# 新栈运行须知（官方 pico-cli，一页速查）

本项目已从 0.10.7 手写脚本迁移到**官方 PICO CLI + 插件工作流**。日常开发只用官方命令，
不要再用 `archive/0.10.7/` 里的 QT/AVD/JDK 硬编码脚本。

“新栈”指工具工作流迁移。业务 SDK 已于 2026-09-18 升级并以 **6.1 为基准**：
当前项目实际配置为 Spatial BOM `6.1.9`（设备运行时 6.1.0）、AGP `8.7.3`、
Kotlin `2.0.21`、Gradle `8.10.2`、compile/target SDK `36`，APK 仅包含 `arm64-v8a`。
升级的 API 迁移点与 6.1 模拟器验证证据见 [本地开发环境](本地开发环境.md)。

## 0. 一次性准备（每台机器）
- 需要 Node ≥ 18。安装 CLI：`npm install -g @picoxr/pico-cli`（`pico-cli --version` 验证）。
- 已为当前项目执行过：
  `pico-cli setup --agent-tool traecli --scope local --platform spatial --project <本工程绝对路径> --yes`
  产物：`.trae/skills/`（17 个官方技能）、`.trae/mcp.json`、`AGENTS.md`、`PICO-SPATIAL-AGENTIC-TOOLS.AGENTS.md`。
- **重要**：setup 后需**新开一个 Trae CLI 会话**（或重启工具），新 Skills/MCP 才会加载。
- 环境体检：`pico-cli doctor --format json`（`error` 按其 `nextAction` 修，`warn` 按当前工作流判断是否影响使用）。
- 工具链目标：PICO OS 6.1 + Android Studio 2025.1.x。
- 本机实际环境、已验证版本及与目标的差异见 [本地开发环境](本地开发环境.md)。

## 1. 日常命令（都交给官方 CLI）
```bash
# 模拟器
export PICO_HOME="$HOME/Library/PICO/sdk"
export PICO_EMULATOR_HOME="$PICO_HOME/6.1/emulator" # 解决旧根目录布局遮蔽新版 bundle
pico-cli emulator doctor                 # 体检
pico-cli emulator list                  # 包括本机已有的非受管 AVD
pico-cli emulator start --avd Pico_Emulator_6_1 --bundle-version 6.1.0 --format json
pico-cli shell getprop sys.boot_completed # 返回 1 才算开机完成
pico-cli emulator status                 # 状态

# 构建（仍用工程自带 Gradle wrapper）
JAVA_HOME="/Applications/Android Studio Preview.app/Contents/jbr/Contents/Home" \
  ./gradlew :app:assembleDebug

# 安装 / 拉起 / 日志
pico-cli app install app/build/outputs/apk/debug/app-debug.apk
pico-cli app launch com.pico.spatial.sample.hotlinechamber --activity .platform.LaunchActivity
pico-cli app logcat --lines 200 --level E
pico-cli app watch-crash com.pico.spatial.sample.hotlinechamber --start
```
更多命令族：`pico-cli --help`、`pico-cli emulator --help`、`pico-cli app --help`。

## 2. 本机特殊注意（这台 Mac / Trae 沙箱）
- npm 报 `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` 时（保留 SSL 校验，不要关 strict-ssl）：
  ```bash
  security find-certificate -a -p /System/Library/Keychains/SystemRootCertificates.keychain > /tmp/sysroots.pem
  security find-certificate -a -p /Library/Keychains/System.keychain >> /tmp/sysroots.pem
  NODE_EXTRA_CA_CERTS=/tmp/sysroots.pem npm install -g @picoxr/pico-cli
  ```
  运行期若 CLI 也要联网（如下载模拟器 bundle），同样在命令前加 `NODE_EXTRA_CA_CERTS=/tmp/sysroots.pem`。
- setup 时 Agent Vault / Graphify / profiler 可能因本机 uv+Python 环境报错而跳过——
  **不影响**构建、模拟器、安装运行；需要性能分析时再单独修（`PICO_HOME` 等）。

## 3. 验证“进入房间”成功
以根目录 `AGENTS.md` 的 5 条冒烟判据为准：构建/安装成功、Stage `HOTLINE_CHAMBER` 进 foreground、
4 条“已加载模型”日志且无 Main Thread 异常、Watchdog `lastRenderTime` 持续递增、无反复 entity invalid。
空间容器截图可能是黑图、2D tap 无法驱动空间手势，属正常，需人工在模拟器窗口确认。
